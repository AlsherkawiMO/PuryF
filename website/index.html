Website API demo

Upload. Convert. Download.

This developer demo connects to your configured hosted-mode preview API. Enter your own customer token. Tokens stay in this page's memory. Public websites should authenticate users through their backend; never embed a shared API key in frontend code.

Hosted preview supports text, images and PDFs. Office uploads are rejected. Default: 20 files, 10 MiB each.

Ready. Start the API with your hosted configuration first.

Serve only the website folder on localhost:8080 and configure that exact allowed origin. This demo uses polling for job progress.
